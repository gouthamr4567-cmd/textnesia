# Riot Reply

💥 REPLY RIOT

“Bad replies. Big consequences.”

Build a complete, polished, highly interactive frontend-only web application called:

REPLY RIOT

Tagline:

“Bad replies. Big consequences.”

This is a deliberately useless but technically impressive comedy-experiment chat application for a college hackathon.

IMPORTANT:

THIS PHASE IS FRONTEND ONLY.

Do NOT connect Supabase.

Do NOT create a real backend.

Do NOT require authentication.

Do NOT create API keys.

Do NOT use external AI APIs.

Use realistic mock/local state so the entire experience can be demonstrated interactively.

However, structure the code cleanly so Supabase realtime can be integrated later without rebuilding the frontend.

---

🎯 CORE CONCEPT

REPLY RIOT is a two-person chat experience that judges people's texting behaviour.

The user sends normal messages.

The application analyzes the conversation and detects:

- 🧊 Dry replies

- 👀 Seen without reply

- 🐢 Late replies

- 👻 Ghosting

- 🧢 Gen-Z vocabulary

- 🚩 Red flags

- ⌨️ Excessive typing followed by tiny replies

- 💀 Conversation death

Then the app responds with:

- 😂 Roasts

- 🪨 Pebble/stone punishments

- 👊 Cartoon punches

- 🔨 Hammer attacks

- 🧱 Brick attacks

- 🏔️ Boulder attacks

- 🚨 Cyber Crime alerts

- 👮 Stone Police

- ❤️ Special Sympathy

- 📈 Relationship Market crashes

- ⚖️ Chat Court

- 🏆 Achievements

- 🌪️ Chaos Mode

Everything must be obviously fictional, cartoonish and harmless.

🛡️ 31. SAFETY

The punishment system is purely fictional and cartoonish.

Do not depict realistic injury.

Do not encourage actual violence.

Implement a simple frontend moderation layer for serious harmful content.

Normal slang and harmless Gen-Z language should not be blocked.
