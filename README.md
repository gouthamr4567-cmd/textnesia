# TEXTNESIA 🧠

### Bad texts. Convenient amnesia.

TEXTNESIA is a deliberately useless but technically complex comedy web experiment that turns bad texting into crimes, punishments, court cases, relationship-market crashes and fictional memory erasure.

## Features

- Real-time two-device chat
- Bad-text and dry-reply detection
- Synchronized punishments
- Chat Court
- Relationship Stock Market
- Chaos Mode
- Achievement system
- Fictional Memory Eraser
- Incident Vault
- Final Riot Report

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Supabase Realtime
- Vercel

## Disclaimer

The Memory Eraser is purely a fictional comedy simulation. It does not actually delete memories or affect the human brain.
