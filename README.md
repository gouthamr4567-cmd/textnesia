# TEXTNESIA 🧠

### Bad texts. Convenient amnesia.

TEXTNESIA is a deliberately useless but technically complex comedy web application that turns bad texting into crimes, punishments, court cases, relationship-market crashes and fictional memory erasure.

It combines real-time communication, behavioural analysis, gamification, comedy animations and interactive storytelling into one completely unnecessary digital experience.

## ✨ Features

### 💬 Real-Time Chat

- Real-time two-device communication
- Room creation and joining
- Two-user room limit
- Message synchronization
- Online/offline presence
- Typing indicators
- Seen-status synchronization

### 🔍 Communication Behaviour Analysis

The application detects different texting behaviours, including:

- Dry replies
- “K”, “hmm”, “ok” and similar low-effort messages
- Repeated dry texting
- Late replies
- Ghosting
- Gen-Z vocabulary
- Conversation-ending behaviour
- Communication red flags

The analysis is deterministic and implemented using local TypeScript rules.

### 🪨 Cartoon Punishment System

Bad texting behaviour can trigger fictional and harmless punishments such as:

- Pebbles
- Stones
- Bricks
- Hammers
- Boulders
- Cartoon screen shakes
- Cyber Crime alerts
- Stone Police interventions

Punishments are targeted at the person responsible for the message.

All punishments are cartoon-style comedy effects and do not represent real violence.

### 😂 Roast Engine

The application generates funny responses based on texting behaviour.

Examples include:

- “One letter. Zero effort. Maximum consequences.”
- “Bro replied like the keyboard charged per letter.”
- “That ‘hmm’ has the emotional depth of a loading screen.”

### ❤️ Special Sympathy™

After major communication offences, the application displays dramatic and humorous sympathy messages.

Example:

> “You tried. They ghosted. We threw rocks.”

### ⚖️ Chat Court

Serious texting offences can lead to a fictional courtroom experience.

Chat Court includes:

- Case numbers
- Defendants
- Charges
- Evidence
- Defence statements
- Guilty verdicts
- Sentences
- Synchronized court events

Example charges include:

- Excessive “K” usage
- Conversation negligence
- Unauthorized ghosting
- Seen without replying
- Criminal lack of enthusiasm

### 📈 Relationship Stock Market

The relationship begins with a fictional market value.

Different texting behaviours affect the value:

- Dry replies decrease the value
- Ghosting causes major crashes
- Repeated offences damage the market
- Apologies and positive messages can recover the value

The market includes:

- Live value updates
- Price changes
- Market status
- Recent transactions
- Animated graph
- Market crash notifications

### 🏆 Achievement System

Users can unlock achievements for different communication behaviours.

Examples include:

- FIRST OFFENSE
- K MERCHANT
- PROFESSIONAL GHOST
- DRY TEXT LEGEND
- STONE COLLECTOR
- COURT REGULAR
- MARKET CRASHER
- RELATIONSHIP RECOVERY

### 🌪️ Chaos Mode

Chaos Mode combines multiple fictional communication events into one exaggerated experience.

It may trigger:

- Cyber Crime alerts
- Ghosting effects
- Red flags
- Gen-Z overload
- Stone Police
- Relationship Market crashes
- Cartoon punishments
- Roasts
- Special Sympathy™

The result is a completely unnecessary communication collapse.
